§bHorizontal Dividers
§7You can separate logical blocks of text with sleek high-tech lines. No more need to manually copy long strings of characters.

§7To create a line, simply write **§a---§7** or **§a***§7** on a new line (§6at least three consecutive characters§7).

§7Usage examples:
§7• Standard line (dark gray): Simply write §8`---` §7on a new line.
§7• Colored line: Add a color code before the dashes, e.g., §6`---` §7for a gold line or §c`---` §7for a red line.
§7• Bold colored line: Using the bold prefix §l§6`---` §7will make the line visually thicker (2 pixels instead of 1).

§bInteractive Links
§7To create a clickable link to another chapter or subchapter, use the syntax:
§6`[Button Text](file_name)`. §7IMPORTANT! Do not put a space between the closing square bracket '§6]§7' and the opening parenthesis '§6(§7'.

§7Examples:
[Return to Introduction](introduction) §a(This works)
§c[Go to Demo Subchapter] (sub_demo1) §c(This does not work)

§7How it works:
    §7• Text in square brackets §6[like this] §7becomes clickable
    §7• Text in parentheses §6(file) §7must match the .md file name (without extension)
    §7• The link is automatically highlighted in §blight blue §7and underlined
    §7• Clicking instantly loads the target page in the book
